# Personal CV

A personal CV website built with **React** to present my education, skills, experience, projects, certifications, and professional profiles in a clean and responsive format.

## Features

* Responsive CV layout
* Education and experience sections
* Technical skills
* Projects and certifications
* Links to GitHub, LinkedIn, LeetCode, and other profiles
* Printable CV layout

## Tech Stack

* **React**
* **JavaScript**
* **CSS**
* **Vite**
* **React Icons**

## Getting Started

Clone the repository:

```bash
git clone https://github.com/shnefix/cv.git
cd cv
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The website will be available locally through the URL shown by Vite.

## Project Purpose

This project is my personal CV website and is used to present my background, technical skills, projects, and experience in an accessible web format.
